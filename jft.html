About This Project

Just For Tonight

Just For Tonight is an evening meditation literature project of The Core Group of NA.

The project is presented here for daily reading, literature study, Group review, and input from the fellowship.

A.S.I.S. is directly responsible to the NA Groups it serves and provides a service structure through which participating Groups can cooperate and support fellowship projects while remaining responsible for their own literature and service efforts.

The source project file is titled Just for Tonight. The public site uses the title Just For Tonight.
